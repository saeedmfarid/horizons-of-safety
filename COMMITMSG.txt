Ignore generated editions; publish them as release assets

The Word and PDF editions are build outputs of the markdown under
chapters/, not sources. Git stores each new version of a binary in full
rather than as a delta, so committing a 500-page PDF on every revision
would grow the repository without bound and slow every clone.

They are now listed in .gitignore and belong in GitHub Releases instead,
where each version carries its own tag and notes, and where file size
costs nothing.

Also adds .gitattributes so binaries are never line-ending converted and
markdown stays LF on every platform.
